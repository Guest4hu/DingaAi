## Phrasal Verbs de Interface e Dia a Dia para Iniciantes (A2)
Antes mesmo de configurar servidores na nuvem, *phrasal verbs* simples aparecem em qualquer tela de aplicativo, laboratório de aula ou primeiro estágio:
- **Log in / Sign in (fazer login / entrar):** entrar na conta com usuário e senha.
- **Log out / Sign out (sair da conta):** encerrar a sessão em um computador compartilhado.
- **Back up (fazer cópia de segurança):** salvar seus arquivos ou banco de dados antes de alterar algo importante.
- **Plug in (conectar cabo / dispositivo):** ligar carregador, fone ou cabo USB.
- **Turn on / Turn off (ligar / desligar):** ativar ou desativar um recurso, Wi-Fi ou modo escuro.
- **Scroll down / Click on (rolar para baixo / clicar em):** navegar em páginas e menus.
- **Mini-diálogo prático (Laboratório / Suporte de Estágio):**
  - **Estagiário:** *"I can't log in to the sandbox. Should I turn off the VPN?"*
  - **Mentor:** *"Yes, turn off the VPN, scroll down to the login button, and back up your notes before signing out."*
- **Contrastes práticos:**
  - ❌ Evite: *"Enter in the system and exit the account."* → ✅ Prefira: *"Log in to the system and sign out when you finish."*
  - ❌ Evite: *"Click in the button."* → ✅ Prefira: *"Click on the button."*
- **Frases naturais para praticar (🔊):**
  - *"Remember to sign out when you use a shared computer at university."*
  - *"Always back up your project files before updating the library."*
  - *"Scroll down to the bottom of the page and click on the Save button."*
  - *"Please turn on low-data mode if your mobile connection is slow."*

## Phrasal Verbs de Infraestrutura, Código e Deploy (B1)
Em documentação técnica (Microsoft Learn, GitHub) e reuniões de engenharia, *phrasal verbs* são muito mais naturais do que verbos latinos longos:
- **Set up (configurar / preparar ambiente):** montar JDK, IDE, variáveis de ambiente ou projeto.
- **Spin up (subir / inicializar rapidamente um servidor ou container):** criar uma instância de teste em segundos.
- **Roll back (reverter uma versão com problema):** voltar ao *release* anterior estável após um erro em produção.
- **Scale up / Scale out (escalar capacidade vertical ou horizontalmente):** aumentar recursos de máquina ou adicionar novas instâncias.
- **Tear down (desmontar / encerrar ambiente de teste):** apagar recursos temporários na nuvem para evitar custos.
- **Break down (dividir um problema complexo em tarefas menores):** quebrar uma história grande em PRs pequenos.
- **Contrastes práticos:**
  - ❌ Evite: *"We need to revert back the deployment."* (redundante) → ✅ Prefira: *"We need to roll back the deployment."*
  - ❌ Evite: *"Let's make the setup of Java."* → ✅ Prefira: *"Let's set up the Java 25 environment."*
- **Frases naturais para praticar (🔊):**
  - *"Let's set up the Java 25 environment before running Maven."*
  - *"We can spin up a local Docker container for integration testing."*
  - *"If the deployment fails, we will roll back to the previous release immediately."*
  - *"Let's break down this feature into three small pull requests."*

## Phrasal Verbs de Debugging, Investigação e Trabalho em Equipe
Quando algo falha no código ou você precisa alinhar pendências no Slack e na *daily*:
- **Run into (esbarrar em um erro inesperado):** encontrar um bug durante os testes.
- **Figure out (descobrir / desvendar após investigar):** achar a solução de um problema.
- **Look up (pesquisar / consultar uma referência):** checar um código HTTP ou sintaxe na documentação.
- **Narrow down (afunilar / isolar a causa raiz):** reduzir o escopo até encontrar o módulo culpado.
- **Rule out (descartar uma hipótese):** eliminar uma suspeita com base em evidências.
- **Reach out / Follow up / Catch up / Hand off:** pedir ajuda (*reach out*), dar retorno (*follow up*), atualizar o assunto (*catch up*) e passar uma tarefa para outra pessoa (*hand off*).
- **Contrastes práticos:**
  - ❌ Evite: *"I searched the word in Google."* → ✅ Prefira: *"I looked up the error message in the official documentation."*
  - ❌ Evite: *"Call me if you need."* → ✅ Prefira: *"Feel free to reach out if you have any questions."*
- **Frases naturais para praticar (🔊):**
  - *"I ran into a NullPointerException while testing the chat controller."*
  - *"Logs helped us narrow down the bug and rule out network issues."*
  - *"We finally figured out why latency increased on slow connections."*
  - *"Feel free to reach out if you want to catch up after the standup."*

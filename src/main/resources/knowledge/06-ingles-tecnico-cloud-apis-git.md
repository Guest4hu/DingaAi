## Termos de APIs REST e Back-end
- **Endpoint:** endereço de uma rota da API (ex.: `/api/chat`).
- **Payload:** os dados enviados ou recebidos no corpo (*body*) de uma requisição JSON.
- **Latency (Latência):** tempo entre enviar uma requisição e receber a resposta — crítica em redes móveis lentas.
- **Fallback:** plano B automático quando um serviço externo falha ou está sem internet (ex.: cair do LLM remoto para o modo RAG local).
- **Throughput / Rate limit:** quantidade de requisições suportadas ou limite imposto por uma API gratuita.

## Termos de Cloud e Git no Dia a Dia
- **Deploy:** publicar a aplicação em um servidor para que outras pessoas acessem via link.
- **Environment Variable (Variável de Ambiente):** configuração externa segura (como `GEMINI_API_KEY` ou `PORT`) que não deve ser colocada no código-fonte.
- **Repository / Branch / Pull Request (PR):** repositório do projeto, ramificação de código e pedido de revisão antes de unir alterações.
- **Troubleshooting:** investigação passo a passo para encontrar e corrigir a causa de um erro.
- **Warning vs. Error:** *warning* é um alerta que não trava o sistema; *error* interrompe a operação.

## Simple Past: Verbos Regulares e Irregulares
O **Simple Past** descreve ações concluídas no passado — muito útil em *daily standups* e relatos de projetos.
- **Verbos regulares:** recebem **-ed** (*studied*, *worked*, *tested*, *deployed*).
- **Verbos irregulares comuns em tecnologia:** *write -> wrote*, *read -> read*, *build -> built*, *find -> found*, *fix -> fixed* (regular!).
- Perguntas e negativas no passado usam **did / didn't** com o verbo principal no infinitivo sem *to*:
  - *"Yesterday I built a small Java prototype."*
  - *"Did you test the API endpoint?"* — *"No, I didn't finish the tests yet."*

## Conectores Essenciais para Estruturar Ideias
Para sair de frases soltas no nível A2, conecte causa, contraste e sequência:
- **First / Then / After that** (sequência): *"First I read the docs, then I wrote the code."*
- **Because** (motivo) e **So** (consequência): *"I practiced English because the documentation is in English."*
- **But / However** (contraste): *"The task was hard, but our team solved it."*

## Simple Past: Verbos Regulares e Irregulares
O **Simple Past** descreve ações concluídas em um momento definido do passado (*yesterday, last night, last week, two days ago*) — a base para relatar o que você estudou ou implementou em aula, no estágio e em *daily standups*.
- **Verbos regulares (+ `-ed`):** *worked*, *studied*, *tested*, *fixed*, *deployed*, *saved*, *opened*, *pushed*.
- **Verbos irregulares mais usados em estudos e tecnologia:** *write → wrote*, *read → read* (pronúncia `/red/`), *build → built*, *find → found*, *run → ran*, *go → went*, *make → made*, *take → took*, *get → got*, *send → sent*, *understand → understood*.
- **Perguntas e negativas:** use **did** ou **didn't** + verbo principal na **forma base** (nunca conjugue o verbo duas vezes).
- **Contrastes práticos:**
  - ❌ Evite: *"Yesterday I work on the login page."* → ✅ Prefira: *"Yesterday I worked on the login page."*
  - ❌ Evite: *"I didn't finished the exercise."* → ✅ Prefira: *"I didn't finish the exercise."*
  - ❌ Evite: *"Did you went to the lab yesterday?"* → ✅ Prefira: *"Did you go to the lab yesterday?"*
- **Frases naturais para praticar (🔊):**
  - *"Yesterday I built a small Java prototype for class."*
  - *"We found a bug in the login screen and fixed it before lunch."*
  - *"Did you test the API endpoint last night?"*
  - *"No, I didn't finish the unit tests yet, so I will finish them today."*

## Conectores Essenciais para Estruturar Ideias e Relatos
No nível A2, conectar causas, consequências, contrastes e ordem cronológica transforma frases soltas em explicações claras:
- **Sequência (passo a passo):** **First**, **Then**, **After that**, **Finally**.
- **Motivo e consequência:** **Because** (porque — motivo) e **So** (então / por isso — consequência).
- **Contraste:** **But** (mas) e **However** (no entanto — ótimo em relatórios e e-mails).
- **Tempo simultâneo:** **While** (enquanto) e **When** (quando).
- **Contrastes práticos:**
  - ❌ Evite: *"I studied English for read the docs."* → ✅ Prefira: *"I studied English to read the docs."* / *"I studied English because the docs are in English."*
  - ❌ Evite: *"The bug was hard, so I didn't give up."* (contraste pede *but*) → ✅ Prefira: *"The bug was hard, but I didn't give up."*
- **Frases naturais para praticar (🔊):**
  - *"First I read the documentation, then I wrote the code, and finally I ran the tests."*
  - *"I practiced English because the tutorial was in English, so now I read faster."*
  - *"The exercise was challenging, however our study group solved it together."*
  - *"I took notes while I watched the beginner lesson."*

## Comparativos, Planos Futuros e Mini-Diálogo no Estágio (A2)
Para comparar soluções técnicas e combinar os próximos passos com colegas ou professores:
- **Comparativos:** adjetivos curtos recebem **-er + than** (*faster than*, *lighter than*, *simpler than*); adjetivos longos usam **more ... than** (*more reliable than*, *more accessible than*). Irregulares: *good → better*, *bad → worse*.
- **Planos futuros simples:** use **going to** para planos já decididos (*"I'm going to review the PR"*) e **will** para decisões na hora ou compromissos (*"I will test it right now"*).
- **Mini-diálogo prático (Acompanhamento de tarefa com tutor/colega):**
  - **Colega:** *"Hey! Did you finish the quiz module yesterday?"*
  - **Aluno:** *"Almost! I wrote the controller and ran the server, but I didn't test the offline mode yet."*
  - **Colega:** *"No problem. Is the new version faster than the old one?"*
  - **Aluno:** *"Yes, it is much faster. Today I'm going to finish the tests and update the README."*
- **Contrastes práticos:**
  - ❌ Evite: *"Local RAG is more fast than remote API."* → ✅ Prefira: *"Local RAG is faster than a remote API."*
  - ❌ Evite: *"I going to study tonight."* → ✅ Prefira: *"I'm going to study tonight."*
- **Frases naturais para praticar (🔊):**
  - *"Local RAG is faster than waiting for a slow mobile network."*
  - *"Today I'm going to review the pull request and update the README."*
  - *"I will test the offline fallback mode before our presentation."*

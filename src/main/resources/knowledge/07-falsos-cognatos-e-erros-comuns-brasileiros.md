## Falsos Cognatos Clássicos (False Friends)
Muitas palavras em inglês parecem português, mas têm significados bem diferentes:
- **Actually** ≠ "atualmente": significa **na verdade / de fato**. ("Atualmente" = *currently* / *nowadays*.)
- **Pretend** ≠ "pretender": significa **fingir**. ("Pretender" = *intend* / *plan*.)
- **Push / Pull:** *Push* = **empurrar** (e no Git significa *enviar* commits); *Pull* = **puxar** (e no Git significa *baixar* commits).
- **Library** ≠ "livraria": significa **biblioteca** (ou biblioteca de código em programação). ("Livraria" = *bookstore*.)
- **Attend** ≠ "atender": significa **frequentar / comparecer** (*"attend a class"* = assistir à aula). ("Atender cliente" = *assist* / *serve*.)
- **Support** ≠ "suportar (aguentar)": significa **apoiar / dar suporte**. ("Aguentar" = *stand* / *tolerate*.)
- **Parents** ≠ "parentes": significa **pais** (pai e mãe). ("Parentes" = *relatives*.)

## Erros Gramaticais Frequentes para Evitar
- Não traduzir *"Eu tenho 20 anos"* como *"I have 20 years"* -> em inglês usa-se **to be**: *"I am 20 years old."*
- Não usar *"make a question"* -> o correto é **ask a question** (*fazer uma pergunta*).
- Em inglês técnico, **information**, **feedback**, **software** e **code** (no sentido geral) são incontáveis: não recebem `-s` (*"useful information"*, nunca *"informations"*).

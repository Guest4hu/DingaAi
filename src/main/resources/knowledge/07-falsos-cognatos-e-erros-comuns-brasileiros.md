## Falsos Cognatos Clássicos (False Friends) no Dia a Dia e na Tecnologia
Muitas palavras em inglês parecem português, mas têm significados bem diferentes — conhecê-las evita mal-entendidos em sala de aula, estágios, entrevistas e documentação:
- **Actually** ≠ "atualmente": significa **na verdade / de fato**. ("Atualmente" = **currently** / **nowadays**.)
- **Pretend** ≠ "pretender": significa **fingir**. ("Pretender" = **intend** / **plan**.)
- **Push / Pull:** **Push** = *empurrar* (no Git, enviar commits); **Pull** = *puxar* (no Git, baixar atualizações).
- **Library** ≠ "livraria": significa **biblioteca** (ou biblioteca de código). ("Livraria" = **bookstore**.)
- **Attend** ≠ "atender": significa **frequentar / assistir a uma aula ou evento**. ("Atender cliente" = **assist** / **serve**.)
- **Support** ≠ "suportar (aguentar)": significa **apoiar / dar suporte**. ("Aguentar" = **stand** / **tolerate**.)
- **Parents** ≠ "parentes": significa **pais** (pai e mãe). ("Parentes" = **relatives**.)
- **Resume (substantivo)** ≠ "resumo": significa **currículo**; como verbo (*to resume*) significa **retomar**. ("Resumo" = **summary**.)
- **Data** ≠ "data do calendário": significa **dados**. ("Data no calendário" = **date**.)
- **Pasta** ≠ "pasta de arquivos": *pasta* em inglês é **macarrão**! ("Pasta de arquivos no computador" = **folder** / **directory**.)
- **College** ≠ "colégio (ensino médio)": em inglês significa **faculdade / universidade**. ("Ensino médio" = **high school**.)
- **Contrastes práticos:**
  - ❌ Evite: *"Actually I work as an intern."* (se você quis dizer "Atualmente") → ✅ Prefira: *"Currently, I work as an intern."*
  - ❌ Evite: *"I pretend to study cloud computing."* → ✅ Prefira: *"I intend to study cloud computing."*
  - ❌ Evite: *"Put the Java file inside the pasta."* → ✅ Prefira: *"Put the Java file inside the folder."*
- **Frases naturais para praticar (🔊):**
  - *"Actually, I study technical English every night, and currently I am learning Cloud APIs."*
  - *"I intend to become a backend developer after college."*
  - *"Please save the project files inside the main folder and update your resume."*
  - *"Our team uses an open-source library to process JSON data."*

## Erros Gramaticais Frequentes de Brasileiros para Evitar
Padrões clássicos de tradução literal do português que você pode eliminar hoje mesmo:
- **Idade com `to be`:** nunca use *have* para idade.
- **Fazer uma pergunta:** sempre **ask a question** (nunca *make a question*).
- **Substantivos incontáveis em inglês técnico:** **information**, **feedback**, **software**, **advice**, **knowledge** e **code** (no sentido geral) não levam `-s` no plural.
- **Preposições fixas:** **depend on** (nunca *depend of*), **explain to me** (nunca *explain me*), **go home** (sem *to*).
- **Verbos sem `to be` extra:** **I agree** (nunca *I am agree*).
- **Passado negativo (`didn't`):** sempre com verbo na forma base.
- **Contrastes práticos:**
  - ❌ Evite: *"I have 20 years and I want to make a question."* → ✅ Prefira: *"I am 20 years old and I want to ask a question."*
  - ❌ Evite: *"Thanks for the informations and feedbacks!"* → ✅ Prefira: *"Thanks for the information and feedback!"*
  - ❌ Evite: *"I am agree with you, it depends of the network."* → ✅ Prefira: *"I agree with you, it depends on the network."*
  - ❌ Evite: *"Could you explain me this bug?"* → ✅ Prefira: *"Could you explain this bug to me?"*
- **Frases naturais para praticar (🔊):**
  - *"Can I ask a question about this API endpoint?"*
  - *"Thank you for the helpful feedback and clear information."*
  - *"It depends on the network latency and local cache."*
  - *"I agree with your pull request, so I approved it."*

## Mini-Diálogo Prático: Evitando Falsos Cognatos na Aula e no Estágio (A2)
Veja como as escolhas certas deixam sua fala natural em situações reais:
- **Professor:** *"Are you attending the cloud workshop this semester?"*
- **Aluno:** *"Actually, yes! Currently I am studying Azure fundamentals in college."*
- **Professor:** *"Great! Could you share your summary in our shared folder?"*
- **Aluno:** *"Sure! I intend to upload the file tonight and ask a question about the data schema."*
- **Dica de estudo:** quando descobrir um falso cognato novo, salve o par contrastivo (`actually ≠ atualmente`) nos seus **Flashcards SRS** para nunca mais confundir.
- **Frases naturais para praticar (🔊):**
  - *"I attend my programming classes in the evening."*
  - *"Could you explain this error message to me step by step?"*
  - *"I didn't go home until we fixed the login bug."*

## Verbo To Be e Apresentação Inicial
No nível A1, o primeiro passo para ganhar confiança é conseguir se apresentar em aula, no estágio ou em comunidades de tecnologia usando frases curtas, claras e verdadeiras sobre você.
- **Estrutura afirmativa:** **I am** (`I'm`), **You are** (`You're`), **He/She/It is** (`He's/She's/It's`), **We/They are** (`We're/They're`).
- **Forma negativa e interrogativa:** **I am not**, **Is she...?**, **Are you...?** (inverta sujeito e verbo *to be* na pergunta, sem usar *do/does*).
- **Atenção à idade em inglês:** nunca traduza *"tenho X anos"* com *have*; em inglês idade usa **to be** (*am/is/are*).
- **Contrastes práticos:**
  - ❌ Evite: *"I have 21 years."* → ✅ Prefira: *"I am 21 years old."*
  - ❌ Evite: *"You are a developer?"* → ✅ Prefira: *"Are you a developer?"*
  - ❌ Evite: *"My name it is Lucas."* → ✅ Prefira: *"My name is Lucas."*
- **Frases naturais para praticar (🔊):**
  - *"Hi, my name is Ana and I am a Computer Science student in São Paulo."*
  - *"I am 20 years old and I am an intern on the backend team."*
  - *"I am learning English to read technical documentation with confidence."*
  - *"My team is very supportive and open to beginner questions."*

## Simple Present para Rotina, Estudos e Hábitos
O **Simple Present** expressa hábitos diários, horários fixos, fatos gerais e o que um software faz por padrão.
- **Regra de ouro (he / she / it):** na afirmativa da 3ª pessoa do singular, adicione **-s**, **-es** ou **-ies** ao verbo (*work → works*, *study → studies*, *watch → watches*, *fix → fixes*, *run → runs*).
- **Perguntas e negativas:** use os auxiliares **do** (I/you/we/they) e **does** (he/she/it) com o verbo principal sempre na **forma base** (sem `-s`).
- **Advérbios de frequência:** **always**, **usually**, **often**, **sometimes**, **rarely**, **never** (vêm antes do verbo principal, mas depois do *to be*).
- **Contrastes práticos:**
  - ❌ Evite: *"She study Java every night."* → ✅ Prefira: *"She studies Java every night."*
  - ❌ Evite: *"Does the API returns JSON?"* → ✅ Prefira: *"Does the API return JSON?"*
  - ❌ Evite: *"I no understand this error."* → ✅ Prefira: *"I don't understand this error."*
- **Frases naturais para praticar (🔊):**
  - *"I study programming every evening after work."*
  - *"Does the application run on Java 25?"*
  - *"Yes, it returns a lightweight JSON response in milliseconds."*
  - *"I usually practice English for 15 minutes before class."*

## Vocabulário de Interface de Software, IDE e Sala de Aula (A1)
Quem está começando em tecnologia encontra dezenas de botões e menus em inglês no VS Code, IntelliJ, navegador e GitHub. Reconhecer esses comandos evita travar no dia a dia:
- **Menus e ações de IDE/navegador:** **File** (arquivo), **Folder** (pasta), **Save** (salvar), **Open** (abrir), **Run** (executar), **Settings** (configurações), **Search** (pesquisar), **Download** (baixar), **Upload** (enviar arquivo), **Sign in / Log in** (entrar), **Submit** (enviar formulário).
- **Perguntas essenciais em aula ou estágio:**
  - *"Could you repeat that, please?"* (Você pode repetir, por favor?)
  - *"Could you speak a bit slower?"* (Você pode falar um pouco mais devagar?)
  - *"Where is the Settings button in this IDE?"* (Onde fica o botão de Configurações nesta IDE?)
  - *"How do you spell that word?"* (Como se soletra essa palavra?)
- **Mini-diálogo prático (Primeiro dia de estágio / laboratório):**
  - **Mentor:** *"Hi! Are you the new intern? Let's open the project folder."*
  - **Aluno:** *"Yes, I am! Thank you. Do I click Run after I save the file?"*
  - **Mentor:** *"Exactly. Save the file first, then click Run to start the server."*
  - **Aluno:** *"Got it! Could you repeat the shortcut to open Settings?"*
- **Contrastes práticos:**
  - ❌ Evite: *"I want save the archive."* → ✅ Prefira: *"I want to save the file."*
  - ❌ Evite: *"Repeat, please."* (pode soar seco) → ✅ Prefira: *"Could you repeat that, please?"*
